User Management System

This is a simple CRUD (Create, Read, Update, Delete) application built using Advanced Java, JSP, Servlets, and MySQL. The project allows users to perform basic operations on a user database.

Features

Add new users
View user details in a tabular format
Edit and update user information
Delete users from the database

Technologies Used
Backend: Java, JSP, Servlets
Frontend: HTML, CSS, JavaScript
Database: MySQL
Server: Apache Tomcat

Usage

Fill in the form to add a new user.
View the list of users.
Click on "Edit" to modify user details.
Click on "Delete" to remove a user.
